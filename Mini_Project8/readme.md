## Project Overview

This project demonstrates an **Azure AI Agent-based Cloud Agent system** that supports multi-tool execution, workflow orchestration, and agent tracing.

It showcases how modern **Agentic AI systems are designed using Azure AI Foundry concepts, MCP (Model Context Protocol), and multi-agent orchestration patterns**.

The system includes:
- Sequential workflows
- Parallel workflows
- Multi-tool agent execution
- Planner-Executor architecture
- Agent tracing and debugging capabilities

## How It Works

### Sequential Workflow
1. Agent receives user input
2. Planner defines execution steps
3. Executor runs tools sequentially
4. Results are aggregated

---

### Parallel Workflow
1. Agent decomposes tasks
2. Multiple tools execute simultaneously
3. Results are merged
4. Final output is generated

---

### Planner–Executor Flow
1. Planner defines strategy
2. Executor performs actions
3. Feedback loop improves reasoning
4. Final structured response returned
