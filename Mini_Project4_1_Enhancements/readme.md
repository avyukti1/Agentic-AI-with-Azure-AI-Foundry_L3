# Agentic AI with Azure AI Foundry (L3) - Mini Project 4.1

## React + Node.js Full Stack HR, IT & ServiceNow Multi-Agent System

---

## Project Overview

This project is a **full-stack Agentic AI system** built using React (frontend) and Node.js (backend), simulating enterprise HR, IT, and ServiceNow-style AI agents.

It demonstrates how multiple AI agents can operate within a single application ecosystem to handle different business domains such as HR support, IT support, and service ticket automation.

The system follows **Agentic AI architecture principles** aligned with Azure AI Foundry concepts.

---

## Objective

The main objective of this project is to:

- Build a full-stack Agentic AI system using React and Node.js
- Simulate HR, IT, and ServiceNow AI agents
- Demonstrate multi-agent orchestration in a web application
- Implement backend agent logic with frontend interaction
- Understand enterprise AI service workflows

## System Architecture

1. User interacts with React frontend
2. Request is sent to Node.js backend server
3. Backend routes request to appropriate AI agent:
   - HR Agent
   - IT Agent
   - ServiceNow Agent
4. Agent processes request based on logic and prompts
5. Response is returned to frontend
6. UI displays structured AI response
