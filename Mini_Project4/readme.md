# Agentic AI with Azure AI Foundry (L3) - Mini Project 4

## React-Based Agentic AI Application

---

## Project Overview

This project demonstrates a **React-based Agentic AI application** developed as part of the Azure AI Foundry (L3) learning track.

It focuses on building a modern frontend interface for interacting with AI-driven agentic systems, enabling users to communicate with AI assistants through a web-based React application.

The system is designed to simulate how enterprise AI assistants are exposed through modern web interfaces.

---

## Objective

The main objective of this project is to:

- Build a React frontend for an Agentic AI system
- Integrate AI-driven workflows into a web UI
- Demonstrate frontend-to-AI interaction patterns
- Simulate Azure AI Foundry-style application exposure layer
- Understand how AI agents are consumed via modern web applications

## How It Works

1. User interacts with the React UI
2. Input is captured through chat or form components
3. Request is sent to backend AI service (or mock layer)
4. AI agent processes the input
5. Response is returned and displayed in UI
6. Conversation history is maintained in frontend state

---

## Example Use Case

User Input:
"What is the leave policy?"

System Flow:
- React UI captures input
- Request sent to AI agent backend
- Agent processes HR policy context
- Response returned
- UI renders AI-generated answer
