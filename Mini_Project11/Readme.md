## Memory-Based Session-Aware AI Assistant

---

## Project Overview

This project demonstrates a **Memory-Enabled Session-Aware AI Assistant** designed as part of the Agentic AI with Azure AI Foundry (L3) learning track.

The assistant is capable of maintaining **conversation context across sessions**, enabling more intelligent, personalized, and continuous interactions.

It simulates how modern AI systems retain memory and use past interactions to improve response quality.

## How It Works

1. User starts a conversation session
2. System initializes session memory
3. Each user input is stored in memory
4. Previous context is retrieved during response generation
5. AI generates responses based on both:
   - Current input
   - Historical conversation context
6. Session memory is updated continuously

## Example Use Case

### Conversation Flow:

User:
"What is my leave balance?"

Assistant:
"Your leave balance is 12 days."

User (later in same session):
"Can I use 3 days next week?"

Assistant:
"Yes, you can use 3 days. After approval, your remaining balance will be 9 days."
