## Build Reasoning Agent using ReAct V2 (Enhanced with Azure OpenAI)

---

## Project Overview

This project is an **enhanced version of a ReAct-based reasoning agent**, upgraded to support **Azure OpenAI integration and modular LLM client architecture**.

It extends the original ReAct framework by introducing:

- Azure OpenAI-powered reasoning
- Modular LLM client layer
- Enhanced structured response handling
- Improved tool execution pipeline
- Scalable agent architecture

This project demonstrates how modern **Agentic AI systems integrate reasoning, tools, and cloud LLM services**.

The main objective of this project is to:

## System Architecture

### 1. User Input Layer
- Accepts user query
- Sends request to reasoning engine

### 2. ReAct V2 Reasoning Engine
- Performs step-by-step reasoning
- Decides required actions
- Coordinates tool usage

### 3. LLM Client Layer (Azure OpenAI)
- Handles communication with Azure OpenAI
- Abstracts model interaction logic
- Enables model flexibility

### 4. Tool Execution Layer
- Executes external tools
- Returns structured results to agent

### 5. Response Formatter
- Converts raw outputs into structured responses
- Ensures consistency and clarity

---

## How It Works

1. User submits a query
2. ReAct V2 engine initiates reasoning cycle
3. LLM client sends request to Azure OpenAI
4. Agent selects appropriate tools
5. Tools are executed and results are returned
6. Agent combines reasoning + observations
7. Structured final response is generated

---

## Example Use Case

User Query:
"What is the population of India and its GDP trend?"

Flow:
- Agent reasons about required data
- LLM (Azure OpenAI) assists reasoning
- Tools fetch structured data
- Agent evaluates observations
- Final structured response is generated
