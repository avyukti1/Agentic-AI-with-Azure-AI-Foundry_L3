# Agentic AI with Azure AI Foundry (L3) - Mini Project 2

## HR AI Assistant Application with Agent Integration

---

## Project Overview

This project demonstrates an **HR AI Assistant Application with Agent Integration**, built as part of the Agentic AI with Azure AI Foundry (L3) learning track.

It showcases how an AI assistant can be extended into a **modular agent-based architecture**, where different components (agents) handle specific HR-related tasks such as policy guidance, leave management, and employee support.

---

## Objective

The main objective of this project is to:

- Build an HR AI assistant using Agentic AI principles
- Implement modular agent-based architecture
- Demonstrate AI agent integration patterns
- Apply prompt engineering for HR workflows
- Simulate Azure AI Foundry-style multi-agent design concepts

## How It Works

1. User submits an HR-related query
2. The orchestrator identifies the intent
3. Request is routed to the appropriate agent
4. Agent processes the query using prompt logic
5. Response is generated and returned
6. Final output is delivered to the user
