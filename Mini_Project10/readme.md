# Agentic AI with Azure AI Foundry (L3) - Mini Project 10

## A2A (Agent-to-Agent) and MCP (Model Context Protocol)

---

## Project Overview

This project demonstrates an advanced **Agentic AI system architecture** using the concepts of:

- Agent-to-Agent (A2A) communication
- Model Context Protocol (MCP)
- Multi-agent orchestration design
- Generative AI-based reasoning workflows

The system simulates how multiple AI agents can collaborate, exchange context, and perform structured tasks in a distributed AI environment.

---

## Objective

The objective of this project is to:

- Understand multi-agent communication (A2A systems)
- Implement conceptual MCP-based context handling
- Simulate collaboration between AI agents
- Demonstrate scalable agentic AI architecture design
- Align with Azure AI Foundry-style agent orchestration principles

---

## Key Concepts

### 1. Agent-to-Agent (A2A)

- Multiple AI agents communicate with each other
- Each agent has a specific role
- Agents collaborate to complete complex tasks
- Message-based interaction between agents

Example:
- Research Agent
- Planning Agent
- Execution Agent

---

### 2. Model Context Protocol (MCP)

- Standardized way to pass context between AI models
- Maintains memory and structured context flow
- Enables consistent reasoning across agents
- Supports multi-step task execution

---

### 3. Agentic AI Architecture

- Goal-driven AI system design
- Modular agent components
- Task decomposition and delegation
- Context-aware decision-making

---


---

## Workflow

1. User or system initiates a task
2. Task is broken into subtasks by orchestration logic
3. Agents communicate using A2A messaging
4. Context is shared using MCP-style structure
5. Each agent processes its responsibility
6. Final response is aggregated and returned

---

## Example Use Case

Task: "Generate a business report summary"

Flow:
- Research Agent gathers data
- Analysis Agent processes insights
- Summary Agent generates final output
- MCP maintains context across all steps
