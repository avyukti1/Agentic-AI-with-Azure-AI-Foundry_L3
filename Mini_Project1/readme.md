# Agentic AI with Azure AI Foundry (L3) - Mini Project 1

## HR AI Assistant

---

## Project Overview

This project demonstrates a simple **Agentic AI-based HR Assistant** built using Azure AI concepts and generative AI capabilities.

The solution simulates an intelligent HR assistant that can help employees with:

- HR policy-related queries
- Leave management information
- Company guidelines
- Employee onboarding support
- Basic HR automation responses

---

## Objective

The main objective of this mini project is to:

- Understand Agentic AI concepts in a practical use case
- Simulate an AI-powered HR assistant workflow
- Apply Azure AI Foundry-style prompt and agent design thinking
- Build a lightweight generative AI assistant prototype

---

## Key Features

- Natural language HR query handling
- Context-aware responses using prompt engineering
- Conversational AI interaction model
- Rule-based + AI-assisted response structure
- Scalable design for future agent integration

## Workflow

1. User submits an HR-related query
2. Input is processed through predefined prompt templates
3. AI logic interprets the intent
4. Response is generated based on HR knowledge context
5. Output is returned to the user
