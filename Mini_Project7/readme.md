# Agentic AI with Azure AI Foundry (L3) - Mini Project 7

## Enterprise RAG (Retrieval-Augmented Generation) Pipeline

---

## Project Overview

This project demonstrates an **Enterprise-Grade Retrieval-Augmented Generation (RAG) Pipeline** designed to simulate real-world AI search and knowledge retrieval systems used in organizations.

The system enables intelligent question answering by retrieving relevant information from enterprise documents and combining it with generative AI reasoning.

It is aligned with **Azure AI Search + Azure OpenAI + Agentic AI architecture patterns**.

---

## Objective

The main objective of this project is to:

- Build an enterprise RAG pipeline for document-based AI search
- Enable contextual question answering using enterprise data
- Integrate retrieval systems with generative AI models
- Simulate Azure AI Search + OpenAI based architecture
- Design scalable knowledge-grounded AI systems

## How It Works

1. User submits a query
2. System retrieves relevant documents from enterprise knowledge base
3. Retrieved context is passed to generative AI model
4. Model generates grounded response using retrieved data
5. Final answer is displayed in Streamlit UI

---

## Example Use Case

User Query:
"What is the company leave policy?"

Flow:
- Retrieve HR policy document chunks
- Extract relevant sections
- Pass context to LLM
- Generate structured response
- Return final answer to user
